# Changelog

## 1.0.0

First public release.

- HermesVita app for the PS Vita: animated portrait with ten states, TALK, PANEL, SESSIONS and LINK pages, touch support, Polish and English keyboard
- Voice in (hold SELECT) and out (Piper), spoken answers on or off
- Sessions: new chat, continue an earlier Hermes session
- Bridge with one-use pairing, hashed device tokens, allow-list, rate lock and audit log
- Optional `hermes-vita` plugin: live view of real Hermes sessions
- `hermes-vita` skill for setup and pairing
- App updates from the PC (LINK page, Square)
